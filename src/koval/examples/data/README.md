# Sample data

`sample-1h.csv` is **synthetic**, generated by `examples/generate_sample.py` in the source repository. It is not exchange data, and the prices in it never happened.

It exists so the README quickstart runs offline and produces the same result on every machine, with no API keys and no market-data redistribution terms to worry about. For real candles, use `koval backtest --symbol BTCUSDT --timeframe 1h --from ... --to ...`, which fetches through the exchange adapters and caches locally.
